# Orden de ejecución en MySQL Workbench

Ejecuta los archivos en este orden:

1. `01_base_datos.sql` — crea la base `universidad`, tablas y datos.
2. `02_funciones.sql` — crea las 5 funciones.
3. `03_procedimientos.sql` — crea los 5 procedimientos.
4. `04_triggers.sql` — crea los triggers.
5. `05_pruebas.sql` — ejecuta las pruebas.

También se conserva `universidad.sql` como script completo.

## En MySQL Workbench

Abre cada archivo con **File > Open SQL Script** y ejecútalo con el botón del rayo ⚡.

Después actualiza **Schemas > universidad** para ver Tables, Functions, Stored Procedures y Triggers.
